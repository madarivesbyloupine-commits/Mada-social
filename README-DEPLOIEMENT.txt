DEPLOIEMENT MADA SOCIAL - madasocial.com
========================================

1. Achete le domaine madasocial.com
2. Va sur https://vercel.com - compte gratuit - Add New > Project - Deploy
   OU sur https://netlify.com - Add new site - Deploy manually - glisse ce dossier
3. Dans Vercel > Settings > Domains, ajoute :
   madasocial.com
   www.madasocial.com
4. Chez ton vendeur de domaine, mets les DNS de Vercel
5. Ouvre https://madasocial.com - ton app doit s'afficher
6. Pour Google : https://search.google.com/search-console
   Ajoute https://madasocial.com puis Sitemaps > https://madasocial.com/sitemap.xml
7. Supabase : dans l'app > Parametres > Compte > Supabase
   Colle ton URL + ta cle (ne la partage jamais dans un chat)
   Copie le SQL dans Supabase > SQL Editor > Run

Fichiers inclus : index.html, robots.txt, sitemap.xml, vercel.json
